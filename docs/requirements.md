# KANMAE Requirements

KANMAE is a web application for Kansai University students to check whether restaurants around Kandai-mae are easy to enter before walking there.

The MVP focuses on:

- Map-first restaurant discovery
- Restaurant status pins
- Store detail pages
- Three-choice store status updates
- User visit records with wait-time bucket selection
- Location-based visit verification
- Current crowd status calculation
- Admin store management screens

The app should avoid claiming exact real-time accuracy. Use wording such as "空席情報", "待ち時間目安", and "最終更新".
